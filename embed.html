Free daily horoscope widget for your website

A small card with the day’s horoscope, written by an AI. It updates itself every day in each visitor’s own timezone. Pick a sign or let visitors pick theirs, copy one line of HTML, and you’re done.

How to add it

WordPress

In the editor, add a Custom HTML block and paste the code. For a sidebar: Appearance → Widgets → Custom HTML. On WordPress.com, embedding code may need a plan that allows it.

Wix

Add (+) → Embed Code → Embed HTML, choose “Code”, paste it, then resize the box to the widget’s size.

Squarespace

Add a Code block (or an Embed block with “Code snippet”) and paste the code.

Blogger

Layout → Add a Gadget → HTML/JavaScript, paste the code and save.

Google Sites

Insert → Embed → “Embed code”, paste the code, then drag the box to size.

Notion

Type /embed, paste the link (not the code) and resize the block. Works on dashboards and journal pages.

Start pages

start.me, Protopage and similar: add an embed or web widget with the link, or a feed widget with one of the RSS feeds below.

Any other site

Paste the code anywhere your site lets you add HTML. It’s a plain iframe: no scripts to install.

RSS feeds

For start pages and feed readers (start.me, Protopage, Feedly, Inoreader, Homepage, Glance…). A new line every day.

    Questions

    Is it really free?

    Yes, for any site, personal or commercial. No sign-up, no key, no limits.

    Does it set cookies or track my visitors?

    No. The widget sets no cookies and runs no analytics. Its links only tell this site which website a visit came from.

    How often does it change?

    Every day. Each visitor sees the line for their own date, so it switches at their local midnight.

    Can visitors choose their own sign?

    Yes. Leave the sign on “Visitor picks their sign” and each visitor picks once; the widget remembers it in their browser.

    Will it slow my page down?

    No. It’s small, and the iframe loads lazily, after the rest of your page.

    Is it real astrology?

    No. The lines are written by an AI as an experiment on the Barnum effect: why vague lines feel personal. They aren’t advice.
